# Breast Cancer Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to classify breast cancer cases based on medical diagnostic features.

The project implements two Machine Learning algorithms:

- Logistic Regression
- Random Forest Classifier

The models are trained and evaluated using the Breast Cancer Wisconsin dataset available through Scikit-learn.

## 🎯 Objective

The main objective of this project is to demonstrate how Machine Learning can be used for binary classification of breast cancer data.

The model predicts whether a sample is:

- Malignant
- Benign

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🔬 Machine Learning Process

The project follows these steps:

1. Dataset loading
2. Data exploration
3. Train-test splitting
4. Logistic Regression model training
5. Model evaluation
6. Random Forest model training
7. Model comparison
8. Final prediction

## 📊 Results

| Model | Accuracy |
|---|---:|
| Logistic Regression | 96.49% |
| Random Forest | 95.61% |

Logistic Regression achieved the highest accuracy on the test dataset.
